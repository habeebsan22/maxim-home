# Maxim

Landing page for Maxim — a UK fintech app helping Africans in the UK build credit history, bank, and send money home.

Static site: plain HTML/CSS/JS, no build step or framework.

## Local development

```
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Serves the site at `http://localhost:8834`.

## Structure

- `index.html` — page markup
- `css/styles.css` — styles
- `js/main.js` — header backdrop, FAQ accordion, scroll-reveal animations, email capture
- `assets/` — images, icons, and logos
- `Operation-video/` — archived animated hero background (see its README for restore instructions)
